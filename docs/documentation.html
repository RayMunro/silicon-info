Silicon Info

A floating CPU, GPU and Neural Engine widget for Apple Silicon Macs

Documentation, version 1.0

Copyright © 2026 Ray Munro. All rights reserved.

1. Overview

Silicon Info is a small always-visible panel for the desktop. It breaks Mac activity into the pieces that make up an Apple Silicon chip instead of showing one combined number. The panel has five cards:

  • CPU performance cores and efficiency cores, shown separately.
  • GPU device utilization with render and tiler load.
  • Neural Engine power draw and activity history.
  • Memory unified memory (DRAM) usage, pressure and swap.
  • Power how total power divides between the three blocks.

Each card is a summary. Click a card to expand it into a detailed view, and use the Back control to return.

3. Installation and use

Build

./build.sh

This compiles a release build, draws the app icon, assembles Silicon Info.app and signs it ad hoc for local use.

Run

open "Silicon Info.app"

The widget appears at the top right of the main display. It has no Dock icon or menu bar item. Drag it anywhere by its background. Its position is remembered, and the window is kept fully on screen when a card expands.

Hide process names

The CPU, GPU and Memory views list process names. To hide those lists, for example before sharing your screen, start the widget with the privacy option:

"Silicon Info.app/Contents/MacOS/SiliconWidget" --hide-processes

Quit

pkill SiliconWidget

Memory detail

Apple Silicon uses one pool of unified memory shared by the CPU, GPU and Neural Engine, so this is the DRAM view. It needs no administrator rights.

SectionContents

Power detail

Shows the live split between CPU, GPU and Neural Engine, a stacked two-minute history where the top edge is the total, and average power, peak power and energy in milliwatt-hours for each block since launch.

Core order follows Apple Silicon convention: efficiency cores are numbered first, then performance cores.

6. Privileges and safety

Reading power and frequency needs root access. On launch the widget shows the standard macOS administrator dialog. After approval, a small shell loop runs as root. It does only one thing: it runs powermetrics once per second and writes the text output to /private/tmp/siliconwidget-powermetrics.txt, which the widget reads.

  • The loop exits on its own about a second after the last Silicon Info process quits.
  • Relaunching quickly reuses the running loop and does not ask again.
  • Nothing is sent over the network. The output file contains only power, frequency and process names with CPU and GPU time.
  • If you cancel the dialog, the widget keeps running and shows n/a for the values that need it.
The output file is readable by other local users, so process names on the machine are visible to them while the widget runs.

7. Limitations

macOS does not expose the following on this hardware, so they are not shown:

  • Neural Engine utilization, frequency or per-process use. Only power draw is available.
  • Per-cluster CPU power. Only the CPU total is reported.
  • DRAM bandwidth and DRAM power. macOS refuses the counter subscription even with administrator rights, so only memory usage is shown.
  • Media engine power. It reads zero on this chip.

Per-process GPU time is often zero because few processes keep the GPU busy at any moment.

8. Troubleshooting

SymptomCause and fix
Power shows n/aThe administrator dialog was cancelled. Quit and relaunch, then approve it.
Power graphs are empty after launchHistory fills at one sample per second. Wait a minute.
Neural Engine reads 0 WThe engine is idle. Run something that uses it, such as Core ML work, to see it move.
Widget is off screenDelete the saved position with defaults delete com.raymunro.siliconinfo and relaunch.
Build failsInstall the command line tools with xcode-select --install.
