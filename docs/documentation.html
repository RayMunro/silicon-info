Silicon Info

A CPU, GPU and Neural Engine widget for Apple Silicon Macs

1. Overview

Silicon Info breaks Mac activity into the pieces that make up an Apple Silicon chip instead of showing one combined number. It comes in three forms that share the same data: a floating panel on the desktop, a real desktop widget, and a menu bar item with the live CPU load. The panel has five cards:

  • CPU performance cores and efficiency cores, shown separately.
  • GPU device utilization with render and tiler load.
  • Neural Engine power draw and activity history.
  • Memory unified memory (DRAM) usage, pressure and swap.
  • Power how total power divides between the three blocks.

Each card is a summary. Click a card to expand it into a detailed view, and use the Back control to return. The widget is available in three sizes.

3. Installation and use

Build

Set your own team in project.yml (DEVELOPMENT_TEAM), and change the bundle identifiers and the App Group (875N49PYZ9.com.raymondmunro.siliconinfo, in project.yml and Sources/Shared/WidgetData.swift) to match your team. Then:

./build.sh

This generates the Xcode project from project.yml, then builds and signs SiliconInfo.app together with its widget extension.

Run

open build/Build/Products/Release/SiliconInfo.app

On launch the app asks for your administrator password through the standard macOS dialog. The floating panel appears at the top right of the main display. The app has no Dock icon, but it adds a menu bar item. The panel has a title bar with a close button at the left and the copyright line in the middle. Drag the title bar to move the panel anywhere on screen. Its position is remembered, and the window is kept fully on screen when a card expands.

Hide process names

The CPU, GPU and Memory views list process names. To hide those lists, for example before sharing your screen, start the app with the privacy option:

build/Build/Products/Release/SiliconInfo.app/Contents/MacOS/SiliconInfo --hide-processes

Quit

Use Quit Silicon Info in the menu bar menu, or run:

pkill SiliconInfo

5. Menu bar and desktop widget

Menu bar

The app adds a menu bar item that shows the live total CPU load next to its icon. Its menu shows live CPU, GPU, Neural Engine and memory readings, Free Cached Memory, a Hide Panel or Show Panel toggle for the floating panel, and Quit Silicon Info. If you use a menu bar manager, the icon may be inside its hidden section.

To get rid of the floating panel, click the close button in its title bar, right-click it and choose Hide Panel, or use the menu bar item. It stays hidden across launches, and the desktop widget and menu bar item keep working. Opening the app again from Finder or Spotlight shows the panel.

Desktop widget

Silicon Info includes a WidgetKit widget. Every size carries the copyright line. Run the app once, then right-click the desktop, choose Edit Widgets and search for Silicon Info.

SizeShows
SmallOne component of your choice: CPU, GPU, Neural Engine, Memory or Power. Edit the widget to pick which. When it shows Memory, tapping it frees cached memory.
MediumCPU cores, GPU and Neural Engine side by side, with memory and a power split. Tap the memory bar to free cached memory.
LargeCPU cores, GPU, Neural Engine, memory and power. Tap the memory panel to free cached memory.

Free memory

Tapping the memory area of the widget frees cached memory. The same action is available as a button in the Memory detail view and as Free Cached Memory in the menu bar menu. The widget then shows how much was freed for about a minute.

This runs purge, which empties the disk cache (the Cached files slice). It does not free memory used by apps, since only quitting apps does that, and the cache refills as you work, so things may feel briefly slower. It needs the administrator prompt to have been approved at launch, otherwise the widget says so.

How it works

A widget runs in a sandbox and cannot read hardware counters or run powermetrics. The Silicon Info app therefore keeps sampling and writes a small snapshot file into an App Group container that both the app and the widget are entitled to use. The widget reads that file whenever macOS redraws it.

macOS draws desktop widgets in grey when another app is in front. To keep them in colour, set Widget style to Full-color in System Settings, under Desktop & Dock.
macOS limits how often widgets redraw, so expect an update every several seconds, not every second like the floating panel. Keep the app running for fresh data. If it is not running, the widget shows a small note asking you to open it.

7. Privileges and safety

Reading power and frequency needs root access. On launch the app shows the standard macOS administrator dialog. After approval, a small shell loop runs as root. It does two things: it runs powermetrics once per second and writes the text output to /private/tmp/siliconwidget-powermetrics.txt, which the app reads, and it runs purge when asked to free cached memory.

  • The loop exits on its own about six seconds after the last Silicon Info process quits.
  • Relaunching quickly reuses the running loop and does not ask again.
  • Nothing is sent over the network. The output file contains only power, frequency and process names with CPU and GPU time.
  • If you cancel the dialog, the app keeps running and shows n/a for the values that need it. Free Cached Memory then reports that it needs admin access.
  • The privileged loop also runs /usr/sbin/purge when the app creates a trigger file whose name contains a secret generated for your install. Only the app knows the name, so other local users cannot trigger it.
The output file is readable by other local users, so process names on the machine are visible to them while the app runs.

8. Limitations

macOS does not expose the following on this hardware, so they are not shown:

  • Neural Engine utilization, frequency or per-process use. Only power draw is available.
  • Per-cluster CPU power. Only the CPU total is reported.
  • DRAM bandwidth and DRAM power. macOS refuses the counter subscription even with administrator rights, so only memory usage is shown.
  • Media engine power. It reads zero on this chip.

Per-process GPU time is often zero because few processes keep the GPU busy at any moment.

9. Troubleshooting

SymptomCause and fix
Power shows n/aThe administrator dialog was cancelled. Quit and relaunch, then approve it.
Power graphs are empty after launchHistory fills at one sample per second. Wait a minute.
Neural Engine reads 0 WThe engine is idle. Run something that uses it, such as Core ML work, to see it move.
Floating panel is off screenDelete the saved position with defaults delete com.raymondmunro.siliconinfo and relaunch.
Widget says "Open Silicon Info to update"The app is not running, so no fresh snapshot is being shared. Start the app.
Free Cached Memory says "Needs admin access"The administrator dialog was cancelled or the privileged loop has stopped. Quit and relaunch, then approve the dialog.
Desktop widget looks greymacOS draws widgets in grey when another app is in front. Set Widget style to Full-color in System Settings, under Desktop & Dock.
Floating panel is goneIt was closed or hidden. Use Show Panel in the menu bar menu, or open the app again from Finder or Spotlight.
Widget is missing from the galleryRun the app once. If it still does not appear, copy the app to the Applications folder and open it from there.
Build failsInstall the command line tools with xcode-select --install.
